DNA is double-stranded, and the two strands run in opposite directions. A DnaA box on one strand reads as its reverse complement on the other, so we need to look for both.

Write reverse_complement(pattern): replace each nucleotide with its complement (A with T, C with G, and vice versa), then reverse the string.

Sample input: reverse_complement("AAAACCCGGT")
Sample output: "ACCGGGTTTT"
